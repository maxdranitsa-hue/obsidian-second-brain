# Agent Second Brain

Персональный голосовой ассистент с памятью: Telegram → расшифровка → Claude → заметки (Obsidian) + задачи (Todoist).

## ПЕРВЫЙ ЗАПУСК — УСТАНОВКА

Если в корне **нет файла `.env`** — система ещё не установлена.
Прежде чем делать что-либо ещё, открой **`SETUP.md`** и проведи пользователя по установке шаг за шагом (он, скорее всего, не технарь — веди просто и тепло).

После установки основная «личность» и правила агента живут в `vault/.claude/CLAUDE.md` — работай по ним.
