## Client Detection (CRM)

Упоминание известного клиента:
- **[Клиент A]** → label: client:[client-a]

```
├─ + дедлайн/срочность? → TASK (p1) + client label
├─ + статус (подписали, выиграли, отказали)? → TASK + CRM note
├─ + встреча/звонок/созвон? → TASK (p2) + [[client]] link
└─ просто упоминание? → Add [[client]] link only
```
