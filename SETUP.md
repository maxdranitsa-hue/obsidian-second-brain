# SETUP — установка второго мозга (инструкция для Claude Code)

Ты помогаешь **не-технарю** развернуть Agent Second Brain на его Mac. Веди по шагам, тепло и просто, без жаргона. **Команды выполняй сам.** У человека спрашивай только данные (токены) и подтверждения — по одному, не списком. После каждого шага коротко говори, что сделал и что дальше.

Если какой-то шаг падает — объясни простыми словами и предложи, что сделать. Не иди дальше, пока текущий шаг не прошёл.

---

## Шаг 1. Проверь окружение
Проверь, что установлено: `node`, `git`, `uv`, `claude` (CLI). Выполни `command -v` для каждого.
Чего нет — поставь:
- **uv** (менеджер Python, ставит и сам Python): `curl -LsSf https://astral.sh/uv/install.sh | sh`, затем `export PATH="$HOME/.local/bin:$PATH"`
- **Claude CLI** (нужен боту): `npm install -g @anthropic-ai/claude-code`
- **node / git** — обычно уже есть; если нет: `brew install node git`

## Шаг 2. Зависимости Python
В корне репозитория выполни `uv sync`. Это поставит нужный Python 3.12 и все библиотеки. Дождись успеха.

## Шаг 3. Собери 4 ключа — спрашивай ПО ОДНОМУ
Объясняй, где взять, и жди, пока человек пришлёт. Пиши в `.env` (образец — `.env.example`).

1. **Telegram Bot Token** — «Открой Telegram, найди @BotFather, отправь `/newbot`, придумай имя. Он даст токен вида `7123…:AAH…` — пришли его мне.»
2. **Твой Telegram ID** — «Найди @userinfobot, напиши ему что угодно, он вернёт число — это твой ID. Пришли его.»
3. **Deepgram API Key** — «Зарегистрируйся на console.deepgram.com (есть бесплатный кредит), Settings → API Keys → создай ключ. Пришли его.»
4. **Todoist API Token** — «На todoist.com → Settings → Integrations → Developer, скопируй API token. Пришли его.»

Собрав, запиши `.env`:
```
TELEGRAM_BOT_TOKEN=<1>
DEEPGRAM_API_KEY=<3>
TODOIST_API_KEY=<4>
VAULT_PATH=./vault
ALLOWED_USER_IDS=[<2>]
```

## Шаг 4. Todoist через MCP
Убедись, что `mcp-config.json` содержит сервер `todoist`. Если нужно — пропиши токен Todoist в конфиг MCP.

## Шаг 5. Вход в Claude
Проверь `claude auth status`. Если не залогинен — скажи человеку: «Сейчас откроется браузер, войди под своей подпиской Claude» и запусти вход.

## Шаг 6. Знакомство (личность мозга)
Запусти скилл **`onboarding`** — проведи живое интервью и заполни `about.md`, `vault/goals/`, `vault/MEMORY.md`. (Если about.md уже заполнен — пропусти.)

## Шаг 7. Запусти бота
Выполни в корне: `uv run python -m d_brain`. Бот должен подняться без ошибок.
По желанию предложи автозапуск (launchd), чтобы бот стартовал с включением Mac.

## Шаг 8. Проверка вживую
Попроси человека: «Напиши своему боту в Telegram голосовое или текст — например, "напомни завтра позвонить Ивану".» Убедись, что бот ответил, появилась заметка в vault и задача в Todoist. Поздравь — второй мозг живой.
